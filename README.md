# 事件簿アトラス(jikenbo-atlas)

**本番: https://jikenbo-atlas.vercel.app**

青空文庫のシャーロック・ホームズ翻訳群(大久保ゆう訳ほか)を土台に、正典 60 事件を
「メタデータ層(全数)」と「本文層(青空文庫収録分)」の二層で俯瞰する静的 Web アプリ。

青空文庫に本文の無い 38 事件については、**Project Gutenberg の英語原文を底本に自前で和訳し、
英日対訳で読めるようにする**(L8〜)。訳は段階的に積み、途中経過は充填率として分子と分母の
両方を表示する。

6 ビュー構成: 事件簿ダッシュボード / ロンドン地図 / 人物ネットワーク / 文体レンズ / リーダー /
英日対訳。作品 ID・事件 ID を共通キーとして相互リンクする。詳細は [SPEC.md](SPEC.md)。

## コーパスの現況(2026-08-24 実測)

- 青空文庫ドイル作家ページの公開中 36 作品を全数調査
- 本文取得済み **29 件**(ホームズ判定は本文実測。緋のエチュード=長編を含む)
- 外部ホスト公開のため取得不能 **5 件**(枯葉訳 4・山本ゆうじ訳 1 — ホスト消滅等)
- 非ホームズ 2 件(世界怪談名作集・臨時急行列車の紛失)

一覧と provenance は `data/aozora_works.json`。

## 自前和訳層の現況(2026-09-04 実測)

青空文庫では 60 事件中 22 事件しか本文が読めない。残り 38 事件(長編 3・短編 35)は
Project Gutenberg の 8 巻から原文を採録し、こちらで訳を起こしている。

| | 実測値 |
|---|---|
| 原文を採録した事件 | 38 事件 / 10,869 段落 / 約 45 万語 |
| 訳了した事件 | 15 件(覆面の下宿人・ミルヴァートン・マスグレイヴ家の儀式書・三人ガリデブ・マザリンの宝石・隠居絵具師・三破風館・最後の挨拶・ショスコム荘・ギリシャ語通訳・ライオンのたてがみ・赤い輪・這う男・フランシス・カーファクス姫の失踪・白面の兵士) |
| 充填率 | 2,542 / 10,869 段落(23.4%) |

分割の件数オラクルは**各巻自身の目次**であり、題名の推測では確定しない。収録巻は正典分類と
一致しない — ボール箱(CARD)は本プロジェクトが英国流で「最後の挨拶」に置くが、PG では
#834『回想』の第 II 篇である(実測 2026-09-04)。一覧と provenance は `data/pg_sources.json`。

訳語の基準は `data/yaku_glossary.json`(18 語)。同じサイトのリーダーと対訳ページを読者が
行き来するため、人名・地名の書き方が食い違うと別人・別地と取り違えられる。照合の鍵は原文の
英語名なので、こちらの訳を正解に使う循環がない。**裏づけは二層あり、語ごとに明示する**——

| grounding | 根拠 | 例 |
|---|---|---|
| `corpus` | 青空文庫の既存訳 29 テキストの全数実測。基準表記が実在し、禁じた異表記より多い | ワトソン 333 回 / レストレード 60 回 / ブリクストン 21 回 |
| `internal` | 既存訳に出てこない、あるいは既存訳が割れている語。自前訳が 2 作以上で揃っていることが根拠で、reason を必須にする | バーミンガム(既存訳は **10 回対 10 回の同数**で多数決が取れない)/ クロロホルム(既存訳 0 回) |

混ぜると「既存訳がそう書いている」と「自分の出力が揃っている」の区別が消えるため、分けている。

## ディレクトリ

| パス | 内容 |
|---|---|
| `pipeline/fetch_aozora.py` | 作家ページ実測 → ルビあり zip 取得 → UTF-8 保存(1.2 秒間隔・キャッシュ優先) |
| `pipeline/aozora_parser.py` | 青空文庫記法パーサー。`serialize(parse(x)) == x` を保証 |
| `data/raw/*.txt` | 取得本文(UTF-8・CRLF 保存。git 管理) |
| `data/raw/images/` | パジェット挿絵ほか(git 対象外。fetch 再実行で再現) |
| `data/cache/` | HTTP キャッシュ(git 対象外) |
| `pipeline/fetch_gutenberg.py` | PG 8 巻の取得(1.2 秒間隔・キャッシュ優先・sha256 記録) |
| `pipeline/pg_split.py` | 目次を件数オラクルにした巻→事件の分割。巻専用の分岐を持たない |
| `data/pg_plan.json` | 巻→38 事件の対応(目次項目の通番と題。題は分割時に実測と突き合わせて検算) |
| `data/pg/*.json` | 事件ごとの英語原文(段落列。往復で巻本文スライスを完全復元できる) |
| `data/yaku/*.json` | 自前和訳。原文の段落番号と一対一 |
| `tests/` | pytest。`unit` / `validation`(コーパス前提)マーカー |

## 再現手順

```bash
python pipeline/fetch_aozora.py     # 青空文庫コーパス取得(キャッシュがあれば HTTP アクセスなし)
python pipeline/fetch_gutenberg.py  # PG 8 巻取得(同上)
python pipeline/pg_split.py         # 目次を件数オラクルに 38 事件へ分割(検算に落ちれば例外で止まる)
python pipeline/build_web.py        # web 配信データ生成(web/data/)
python -m pytest -q               # 往復検査・整合ゲート含む全テスト
python -m http.server 8341 --directory web   # ローカル閲覧
```
