# 事件簿アトラス(jikenbo-atlas)

青空文庫のシャーロック・ホームズ翻訳群(大久保ゆう訳ほか)を土台に、正典 60 事件を
「メタデータ層(全数)」と「本文層(青空文庫収録分)」の二層で俯瞰する静的 Web アプリ。

5 ビュー構成: 事件簿ダッシュボード / ロンドン地図 / 人物ネットワーク / 文体レンズ / リーダー。
作品 ID を共通キーとして相互リンクする。詳細は [SPEC.md](SPEC.md)。

## コーパスの現況(2026-08-24 実測)

- 青空文庫ドイル作家ページの公開中 36 作品を全数調査
- 本文取得済み **29 件**(ホームズ判定は本文実測。緋のエチュード=長編を含む)
- 外部ホスト公開のため取得不能 **5 件**(枯葉訳 4・山本ゆうじ訳 1 — ホスト消滅等)
- 非ホームズ 2 件(世界怪談名作集・臨時急行列車の紛失)

一覧と provenance は `data/aozora_works.json`。

## ディレクトリ

| パス | 内容 |
|---|---|
| `pipeline/fetch_aozora.py` | 作家ページ実測 → ルビあり zip 取得 → UTF-8 保存(1.2 秒間隔・キャッシュ優先) |
| `pipeline/aozora_parser.py` | 青空文庫記法パーサー。`serialize(parse(x)) == x` を保証 |
| `data/raw/*.txt` | 取得本文(UTF-8・CRLF 保存。git 管理) |
| `data/raw/images/` | パジェット挿絵ほか(git 対象外。fetch 再実行で再現) |
| `data/cache/` | HTTP キャッシュ(git 対象外) |
| `tests/` | pytest。`unit` / `validation`(コーパス前提)マーカー |

## 再現手順

```bash
python pipeline/fetch_aozora.py   # コーパス取得(キャッシュがあれば HTTP アクセスなし)
python -m pytest -q               # 往復検査含む全テスト
```
